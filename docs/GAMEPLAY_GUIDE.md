# Gameplay Guide

This guide is for participants playing the game during a meeting.

## What You Will See

- A Jeopardy-style board with categories across the top.
- Dollar-value tiles under each category.
- A scoreboard showing each team.
- A clue screen when a tile is selected.

Important:

- The text shown on the clue screen is the `answer`.
- Players respond with the correct `question`, following normal Jeopardy style when appropriate.

Example:

- Clue shown: `A typed superset of JavaScript.`
- Correct response: `What is TypeScript?`

## Basic Round Flow

1. The host selects a tile.
2. The clue appears on screen.
3. Teams discuss or buzz in using the meeting process the host has chosen.
4. A team answers.
5. The host reveals the correct response if needed.
6. The host marks the clue correct or incorrect and updates the board.

## Team Scoring

- A correct response adds the clue value to that team.
- An incorrect response may subtract the clue value if that rule is enabled for the game.
- The scoreboard updates live during play.

## Final Jeopardy

Some games may end with a Final Jeopardy round.

The flow is:

1. The final category is revealed.
2. Teams decide their wagers before seeing the clue.
3. The final clue appears.
4. Teams give one final response.
5. The host judges the responses and applies the wagers.

The host manages wagers and judging. Players only need to provide their final response.

## Board Rules

- Once a tile is played, it cannot be selected again unless the host resets the game.
- Some clues may be special host-only clues such as Daily Doubles.
- The host controls all scoring, reveals, and resets.

## How To Play Smoothly

- Wait until the host finishes reading or presenting the clue.
- Answer with the best matching question rather than repeating the clue.
- Keep answers concise.
- If your team is unsure, decide quickly so the meeting keeps moving.

## What Players Do Not Need To Manage

- Opening or closing clues
- Revealing answers
- Score changes
- Resets
- Config editing

Those controls are handled only by the host.
